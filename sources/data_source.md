# Data Source

## Indian Banking Transactions 2019–2024

**Source:** Kaggle  
**Dataset:** Indian Banking Transactions 2019–2024  
**Dataset Link:** https://www.kaggle.com/code/belbino/indian-banking-transactions-starter-eda/input

### Dataset Used

- 550,000 transaction records
- 79,916 unique customers
- Period: January 2019 – January 2024
- 20 transaction and customer-related fields
- Includes transaction amount, account type, transaction type, channel, state, KYC status, credit score, loan information, and fraud labels

### Important Note

This is a synthetic dataset used for educational and portfolio analysis. The transaction volumes and values should not be interpreted as representative of the entire Indian banking system.

The raw CSV is not included in this repository. It can be accessed from the Kaggle source above.
